# Real World App

A dummy application created for practicing CI/CD workflows. This repository serves as a sandbox for experimenting with pipelines, automation, and deployment strategies in a controlled environment.

---

## Technical Stack

This project was bootstrapped with **Vite**, **React**, and **TypeScript**.

### Core Features
- **React + Vite**: Fast HMR and optimized builds.
- **TypeScript**: Static typing for better developer experience.
- **ESLint**: Pre-configured linting rules.

## Getting Started

### Prerequisites
- Node.js (Latest LTS recommended)
- npm or yarn

### Installation
```bash
npm install
```

### Development
```bash
npm run dev
```

### Build
```bash
npm run build
```
